설치 순서

  1. 설치파일 받기 — 위의 최신 버전 다운로드.사무실에 늘 켜 두는 PC 에 설치하세요. 그 PC 가 서버 역할을 합니다.
  2. 설치 — ‘Windows 의 PC 보호’ → 추가 정보 → 실행, 관리자 확인 → 예.기본 설치 위치: C:\Program Files\ICMS
  3. 관리자 계정 만들기 — 처음 켜면 로그인 화면의 가입 신청. 가장 먼저 가입한 계정이 관리자가 됩니다.
  4. 라이선스 등록 — 30일 안에 도움말 › 라이선스 의 요청 코드를 판매처에 보내고, 받은 키를 등록합니다.

휴대폰에서 쓰기

  1. 같은 Wi-Fi 에 휴대폰을 연결합니다.
  2. PC 프로그램 위쪽의 휴대폰으로 열기 에 나오는 QR 을 휴대폰 카메라로 찍습니다.현장 점검용은 ‘QR 스캔까지’ 쪽을 권합니다. 처음 한 번 ‘연결이 비공개로…’ 가 뜨면 고급 → 계속.
  3. 크롬 ⋮ → 설치 및 바로가기 만들기 → 바로가기 만들기 로 홈 화면 아이콘을 만듭니다.아이폰은 Safari 공유 버튼 → 홈 화면에 추가. ‘이 앱을 설치할 수 없습니다’ 는 정상입니다.
